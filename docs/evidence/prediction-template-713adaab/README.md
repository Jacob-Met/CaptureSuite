## Limits and integration

This is a native, synthetic-fixture qualification on macOS Python 3.12.8, not
Windows, full-repository CI or installed-product qualification. All-null scoring
has zero usable pairs and makes no inference or model-accuracy claim. File limits
are per-input serialized size, not decompressed memory bounds. Exclusive hard-link
publication has no overwrite fallback; there is no whole-package transaction,
parent-directory race guarantee or power-loss durability guarantee.

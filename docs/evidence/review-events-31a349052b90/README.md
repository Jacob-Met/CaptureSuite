## Receiving limits

The view reports the existing reader's loaded subset, not a complete integrity
audit. Optional-file omission, dropped non-object/list records, skipped malformed
JSONL lines and gap coercions remain inherited. Plain-text display and exact
arithmetic do not validate sensor data or scientific conclusions. The authored
fixture is synthetic and contains no participant, account or physical-device
data. No installed application or deployment qualification is implied.

Independent source/consumer review, actual published-head Windows checks and
complete current-parent preservation are required before ordinary integration.
Later results belong in separately pinned receipts; they must not be relabeled
as executions of this initial checkpoint.
